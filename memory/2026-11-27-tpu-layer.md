### HLO·trace (`trace_order.py` → `trace_order_L16.log`, `trace_order_L20.log`; TPU:0 XLA Ops 순서)

- **custom-call 없음** (online softmax 치환 없음, Module 1과 같은 결론).
- attn은 이웃 gemm과 fusion되지 않는다. attn = `qk+scale+mask+rowmax` fusion(259 µs) → softmax exp·sum fusion(270 µs) → `av+정규화` fusion(276 µs) (seq 2048). score pass 3번, Module 1 op 분해와 같다.
- **XLA가 순서를 바꾼다**: `v` gemm은 softmax 뒤, av 바로 앞에서 실행된다. 내보내는 `rope_k`(KV cache)의 rope와 copy는 layer 맨 끝(add2 뒤)에서 실행된다. q·k gemm → qk → softmax → v → av → o+add1+norm2 reduce → gate(+norm2 apply) → up(+silu·mul) → down+add2 → rope_k 출력.
- MLP fusion은 Step 2 B 덩어리와 같은 형태다: `{norm2 apply, gate}`, `{up, silu·mul}`, `{down, add2}`.
